# ElectronicsNetwork

**ElectronicsNetwork** — это Django REST Framework-приложение, моделирующее торговую сеть по продаже электроники.  
Система описывает **иерархию звеньев** (заводы, розничные сети, индивидуальные предприниматели), их **поставщиков**, **продукты** и **задолженности**.

---

## Основные возможности

- Управление **продуктами электроники** (`Product`): название, модель, дата выхода, цена.
- Управление **узлами сети** (`NetworkNode`): заводы, розничные сети, ИП.
- В каждом узле можно указать:
  - поставщика (родительский узел);
  - страну, город, адрес;
  - список продаваемых товаров;
  - задолженность перед поставщиком.
- **Фильтрация**:
  - по стране (`?country=Россия`);
- **Поиск** по названию, стране, городу (`?search=Санкт-Петербург`).
- **Сортировка** по дате создания и уровню звена (`?ordering=created_at, ?ordering=level`).
- В **админке** доступно действие *Clear debt* — очистка задолженности у выбранных узлов сети.
- Только **активные пользователи** могут выполнять действия в API.

## Установка и запуск
- Клонируйте репозиторий
- Создайте виртуальное окружение и активируйте его
- Установите зависимости
- Примените миграции
- Создайте суперпользователя(python manage.py csu)
- Запустите сервер

## Адреса документации
- Админ-панель Django http://127.0.0.1:8000/admin/
- API Swagger-документация http://127.0.0.1:8000/swagger/

## Тестирование
python manage.py test network

## Технологии 
- Язык программирования: Python 3.8+
- Веб-фреймворк: Django 3+
- REST API: Django REST Framework 3.10+
- Аутентификация и авторизация: JWT (JSON Web Tokens) через djangorestframework-simplejwt
- Фильтрация и поиск: django-filter, DRF SearchFilter и OrderingFilter
- База данных: PostgreSQL 10+
- Документация API: Swagger и Redoc (через drf-yasg)
- Админ-панель: стандартная Django Admin с кастомными действиями (Admin Actions)
- Управление зависимостями и виртуальной средой: pip и venv
- Форматирование кода: isort
